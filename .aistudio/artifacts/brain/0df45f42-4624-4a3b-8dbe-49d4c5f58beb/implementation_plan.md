# Система бесплатных OTA-обновлений игры через GitHub Releases

Комплексное внедрение встроенной системы Over-The-Air (OTA) обновлений игры на базе бесплатного GitHub Releases API: проверка новых релизов при старте и по кнопке, просмотр списка изменений (changelog), встроенное скачивание APK с индикатором прогресса и запуск системного диалога обновления без потери данных игрока.

## User Review & Critical Decisions

> [!IMPORTANT]
> Выбранные решения согласованы на этапе уточнения требований.

- **Источник обновлений (GitHub Releases API)**: Полностью бесплатный хостинг с версионированием тегов (`v1.2`, `v1.3`), прямыми ссылками на скачивание APK и описаниями изменений (changelog) без необходимости отдельного платного сервера.
- **Точка входа**: Автоматическая проверка при запуске приложения (без назойливой блокировки) плюс ручная кнопка «Проверить обновления» в меню/настройках.
- **Процесс установки**: Загрузка APK внутри игры во временный кэш с динамическим прогресс-баром и вызовом нативного установщика Android через `FileProvider` (`ACTION_VIEW`).

---

## 1. Overview & Core Concept

- **Что это делает**: Позволяет распространять новые версии игры игрокам без Google Play. Как только разработчик публикует новый релиз с прикреплённым APK на GitHub, игра автоматически узнаёт об этом, показывает список новинок и обновляется в один клик.
- **Ключевая ценность**: Игрокам не нужно вручную искать и скачивать файлы в браузере или мессенджерах. Сохранения, баланс, перки и инвентарь полностью сохраняются при обновлении.
- **Целевая аудитория**: Игроки симулятора номеров и коллекционирования SIM-карт.

## 2. User Experience & Visual Design

### Ключевые пользовательские сценарии

1. **Автопроверка при старте**:
   - При холодном запуске игра в фоновом режиме опрашивает GitHub API.
   - Если версия на GitHub выше текущей (`versionCode` или `versionName`), поверх интерфейса появляется компактная анимированная плашка или диалог: «Доступна версия vX.X. Что нового?».
   - Игрок может нажать «Обновить» или «Позже».
2. **Ручная проверка через Меню**:
   - В боковом меню (`GameDrawerContent`) и в настройках появляется раздел «Обновление игры (OTA)».
   - Отображается текущая версия (например, `v1.1 (build 2)`) и статус проверки: «У вас установлена последняя версия» либо кнопка «Проверить снова».
   - Возможность указать свой GitHub-репозиторий (`владелец/репозиторий`) прямо в интерфейсе, чтобы игра проверяла именно релизы владельца.
3. **Загрузка и установка**:
   - При нажатии «Обновить» открывается карточка загрузки в стиле киберпанк/неон игры:
     - Название релиза и дата публикации.
     - Список изменений (Changelog) в стилизованном скролл-блоке.
     - Прогресс-бар с анимацией, процент загрузки и размер (например, `14.2 МБ / 28.5 МБ`).
   - По завершении скачивания автоматически открывается нативный диалог Android «Установить обновление поверх существующего приложения».

### Визуальный стиль и компоненты
- **Палитра**: Тёмная неоновая тема игры (`DarkBg`, бирюзово-циановые и янтарно-золотые акценты, стеклянные границы `GlassBorder`).
- **Компоненты M3**:
  - `ModalBottomSheet` или `AlertDialog` с карточкой релиза.
  - Анимированный `LinearProgressIndicator` во время загрузки.
  - Кнопки с тактильным откликом (Haptic Feedback) и иконками `SystemUpdate`, `Download`, `CheckCircle`.

## 3. Key Product Decisions & Trade-Offs

- **GitHub Releases vs Кастомный сервер**:
  - *Выбор*: GitHub Releases API.
  - *Почему*: 100% бесплатно, неограниченный трафик для открытых репозиториев, встроенное версионирование, защита HTTPS, прямые ссылки на ассеты (`*.apk`).
  - *Альтернативы*: Firebase Hosting или собственный VPS требуют оплаты или сложной настройки CI/CD.
- **Встроенная загрузка vs Браузер**:
  - *Выбор*: Скачивание через корутины/Ktor прямо в приложении с последующим вызовом `FileProvider`.
  - *Почему*: Бесшовный опыт игрока, наглядный прогресс загрузки прямо в интерфейсе без переходов во внешние браузеры.
- **Безопасность Android (FileProvider & Permissions)**:
  - Использование защищённого `FileProvider` с путём `cache-path/updates/`, чтобы не требовать устаревшие разрешения на запись на SD-карту.
  - Корректная обработка разрешения `REQUEST_INSTALL_PACKAGES` для Android 8.0+ с дружелюбным 안내-экраном.

## 4. Technical Architecture & Data Strategy

### Архитектурная диаграмма

```
┌──────────────────────────────────────────────────────────────┐
│                       GitHub Releases                        │
│         https://api.github.com/repos/{owner}/{repo}/...      │
└──────────────────────────────┬───────────────────────────────┘
                               │ JSON (tag_name, assets, body)
                               ▼
┌──────────────────────────────────────────────────────────────┐
│                    OtaUpdateRepository                       │
│  - checkForUpdates(): Result<AppUpdateInfo>                  │
│  - downloadApk(url, targetFile): Flow<DownloadProgress>      │
└──────────────────────────────┬───────────────────────────────┘
                               │ StateFlow<UpdateUiState>
                               ▼
┌──────────────────────────────────────────────────────────────┐
│                      GameViewModel                           │
│  - updateState: StateFlow<UpdateState>                       │
│  - startUpdateDownload()                                     │
│  - triggerInstall(context)                                   │
└──────────────────────────────┬───────────────────────────────┘
                               │ Compose State
                               ▼
┌──────────────────────────────┴───────────────────────────────┐
│                          UI Layer                            │
│  ┌─────────────────────────┐     ┌─────────────────────────┐ │
│  │   GameDrawerContent     │     │    UpdateDialog / Sheet │ │
│  │   Пункт «Обновление»    │     │   - Changelog           │ │
│  │   Текущая версия v1.1   │     │   - Скачивание (45%)    │ │
│  │   Кнопка «Проверить»    │     │   - Кнопка «Установить» │ │
│  └─────────────────────────┘     └─────────────────────────┘ │
│                                                              │
│  ┌─────────────────────────────────────────────────────────┐ │
│  │    Android System Installer (FileProvider + Intent)      │ │
│  └─────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

### Модели данных

```kotlin
data class AppUpdateInfo(
    val versionName: String,
    val versionCode: Int,
    val releaseTitle: String,
    val changelog: String,
    val downloadUrl: String,
    val apkSize: Long,
    val isNewerThanCurrent: Boolean
)

sealed interface UpdateState {
    data object Idle : UpdateState
    data object Checking : UpdateState
    data class Available(val info: AppUpdateInfo) : UpdateState
    data class Downloading(val info: AppUpdateInfo, val progressPercent: Int, val downloadedBytes: Long, val totalBytes: Long) : UpdateState
    data class ReadyToInstall(val apkFile: File) : UpdateState
    data class UpToDate(val checkedAtMillis: Long) : UpdateState
    data class Error(val message: String) : UpdateState
}
```

### Конфигурация Android Manifest & Ресурсы
- Добавление `<uses-permission android:name="android.permission.INTERNET" />`.
- Добавление `<uses-permission android:name="android.permission.REQUEST_INSTALL_PACKAGES" />`.
- Регистрация `<provider android:name="androidx.core.content.FileProvider" ...>` с ресурсом `xml/file_paths.xml`.
